# Sensory_Threshold
Contains data and scripts for all figures presented in "Visual Thresholds Cannot Be Reliably Measured Without Controlling for Mindwandering"

- the main script is "all_figures.m" 
- "data"-folder contains several .mat-files, that will be loaded into "all_figures.m"
- "GetOffset4OverlappingDataPoints.m" and "ONOFFbarplot.m" are helper-functions, which are necessary for several plots
- "figures"-folder contains the resulting figures
